* PanelApp now serves **433 public panels** (the API lists no other status), against HumanMine's 171 lists. **154** of the 171 2021 names are still a panel name and **17** are panels that were renamed; none was removed. **262** current panels have no 2021 list.
* Green genes: 29609 Green gene entries over all 433 panels (4308 distinct symbols); the 171 panels of the 2021 set hold 9676 entries now (3858 distinct) against 10375 in the 2021 lists (2807 distinct).

Some 2021 lists hold the genes of a different panel (see 'Biggest changes': many 2021 lists are copies of each other). Differences of this size are not PanelApp curation: the 2021 lists were mis-made.

## Which panels HumanMine's 2021 set was

All 154 panels whose name survived carry the PanelApp type `rare-disease-100k` (the rare disease panels of the 100,000 Genomes Project), and so do the 17 renamed ones. Today 175 panels have that type: the 171 of the 2021 set plus 4 new. No 2021 list is a panel of any other type (GMS-only, cancer germline, super panels, additional findings): they were added to PanelApp after 2021. So HumanMine's 2021 set is the `rare-disease-100k` type, and `lists --select 100k` reproduces its scope. The policy, all panels, adds the other 258.

Panel types of the current panels (a panel can carry several): `gms-signed-off` 296, `gms-rare-disease` 236, `rare-disease-100k` 175, `gms-rare-disease-virtual` 144, `component-of-super-panel` 55, `cancer-germline-100k` 19, `superpanel` 15, `additional-findings` 8, `gms-cancer-germline-virtual` 7, `research` 1.

Super panels (type `superpanel`, 15): the API gives each its own `genes` list, the union of its child panels' genes, and the children are ordinary panels (type `component-of-super-panel`). Each is treated like any other panel: one list of its own Green genes. No panel is `retired` or otherwise non-public in the list endpoint: retired panels are not served by `/api/v1/panels/` (PanelApp's own help says so), so they are not fetched.

## Naming rule

`<Panel_name>` is the panel name with each space as `_` and every other character kept (commas, `&`, brackets and hyphens all appear in 2021 names). The rule gives the 2021 suffix for 154 of 171 lists; the other 17 are the renamed panels. One current panel name has a character no 2021 name has: `Amyotrophic lateral sclerosis/motor neuron disease`, whose `/` becomes `_`. No two panels give the same list name.

`PL_GenomicsEngland_GenePanel:Radial_dysplasia` is still a panel name (id 247, version 1.25, 47 Green genes against 47 in 2021), so BlueGenes' hard-coded example keeps working under the same name.

## Method and caveats

* 2021 gene identity comes from the archive's member lists (Entrez id, symbol, Ensembl id as then loaded in HumanMine); 2021 symbols can differ from today's HGNC symbols, which is why Ensembl ids are tried first.
* The 2021 PanelApp versions are not recorded anywhere, so a difference cannot be split into curation since 2021 and error in 2021.
* Counts of `now` are the Green genes of each panel at its current version, deduplicated by HGNC id.
