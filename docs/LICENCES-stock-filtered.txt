Filtered stock-source data for the rdfc2im hybrid HumanMine testbed (corrected 2026-11-18, im-9n4.45)
=====================================================================================================

Each directory stock-<source>/ is a subset of an upstream file, cut to the human genes (and the ids that tie to
them) the build needs by tools/subset_raw.py: the data were changed by filtering. Nothing here is original to this
project; each part stays under its upstream licence and must be credited to it. META.json in each group records
a short licence key. The licence of each source was read from the source's own page or file on 2026-11-18; the
record, with the links and wording, is rdfc2im/data/stock_sources.yaml and docs/LICENCES.md.
